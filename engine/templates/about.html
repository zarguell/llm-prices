About

What this is

A deterministic, dependency-free archive of LLM API pricing. Every week a snapshot of models.dev — a free, open catalog of model metadata and prices — is stored in data/snapshots/YYYY-MM-DD.json.gz and this site is rebuilt from the archive.

No usage data, no tokens, no prompts, no visitors tracked. Only public catalog data is published here.

Method

  • Rates are USD per million tokens, exactly as published by models.dev.
  • “Priced” means the model publishes both input and output rates; models without published prices appear in provider tables without rates.
  • Missing cache rates mean the provider publishes no separate cache price (treated as no surcharge/discount listed, not zeroed by this site).
  • Trend charts are log-scale; single-snapshot archives show points, not lines.
  • Change detection diffs consecutive snapshots: added/removed model ids and input/output price moves > 0.
  • The build is pure Python + Jinja2, no JavaScript chart libs; charts are inline SVG generated at build time.

Raw archive

Weekly snapshots live in data/snapshots/ (gzip JSON, one file per week) and are served as-is — use them for your own analysis. Machine-readable current prices: data/latest.json.

Why

Built as the pricing backbone for a private LLM usage report: the local snapshot cache doubles as the price source, so cost math stays reproducible even when upstream prices change.
